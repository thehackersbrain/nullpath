# BerserkArch

**BerserkArch** is a **security-focused Linux distribution** created by
**[[ly4k]]** (thehackersbrain). It's an Arch-based distro tailored for
offensive security / penetration testing workloads — the distro this wiki's
dev machine runs. It bundles the offensive toolchain and is the author's
day-to-day working environment for the research captured in this wiki.

## What it is

- **Arch Linux-based** — rolling, AUR access, the offensive tooling ecosystem.
- **Security-oriented** — preconfigured for pentest / red-team / RE /
  malware-analysis workloads (the author's domain).
- **The author's environment** — the dev box maintaining this wiki runs
  BerserkArch, so the tooling notes here (Impacket, Rubeus, mitm6, certipy,
  etc.) are exercised on it.

## Why it matters to this wiki

- It's the **runtime** for much of the tooling referenced here — the
  "where do I actually run this" answer for the author's workflow.
- It ties the [[ly4k]] project portfolio together with the research areas
  (AD attacks, AD CS, shadow credentials, RE/malware).
